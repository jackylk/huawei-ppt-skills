# 动画与渲染

## 时间与声音

统一 frame/fps 为时间真源。实测旁白句段后排镜头，字幕、强调、转场从同一时间轴推导。TTS 可用环境已有服务或 edge-tts 等工具；注意网络依赖与术语发音。旁白停顿要服务理解，不留无意义空洞，也不吞掉关键句尾。

Remotion 内嵌语音需确认 trim 行为；也可单独构建旁白 WAV 后与视频混流。变速时先 atempo，再按实际播放时长裁剪。禁止为对齐镜头误截语音结尾。音效与配乐克制，压低到不遮盖旁白。每次改稿都重测时间。

## 持续图层与出场时序

- 环境背景、人物、持续设备由全局帧控制，在片段切换时保持挂载与位置。片段局部帧只驱动该段新增动作；不要让所有角色在每个 Sequence 的第零帧重新变透明。
- 出场时间对应具体旁白：先看到任务发起者，再出现工具处理、产物和接收动作。对话尚未讲到的结果与架构不要提前铺满画面。记录每个关键对象的开始帧、到达帧与停留帧。
- 相邻内容可交叠约 12–18 帧淡化，按节奏调整。对象跨段交接时使用相同几何和比例，避免旧对象消失后新对象从空白重现。声音、字幕使用统一时间轴，不因视觉转场截断旁白。
- 检查转场前一帧、切换帧和其后连续帧，持续图层不应闪白、闪退或重复淡入。

## 对象动作

- 图节点、曲线、箭头、运动粒子共享数据与几何函数。节点移动时端点随锚点更新，箭头尖贴目标边界。
- 词条不要先到入口停止、消失，再从出口出现。优先一条连续路径，必要时用弧长重采样控制速度；抵达后把飞行对象与落位对象平滑交接。
- 承载文字的共享对象需要足够的阅读时间。短距离传递可从约 2–3 秒移动、约 1 秒抵达停留起步，按旁白和实际播放检查调整；不要让标签一闪而过。抵达后平滑转成接收状态，再淡出。
- 只保留解释动作所需的连线和箭头；用户删除的装饰箭头不能在后续版本重新出现。
- 主动作后可加轻微惯性、回弹、阴影变化；避免所有对象同时弹跳。镜头可稳定，让对象动作承担叙事。
- 书页必须将纸、文字、横线、高亮放在同一局部坐标组，每帧施加同一个投影/变换。正反面和遮挡要明确。封面也用相同的局部几何；静止页不能越过翻动页露出重复文字。不要仅扭曲纸张轮廓，却把文字画在屏幕坐标。
- 翻页/开书重点检查关闭、25%、50%、75%、落定前一帧、落定帧。手工画出的倾斜四边形与文字变换必须一致；更复杂的透视用 CSS 3D/WebGL 或纹理映射。

## 运行与交付

建议共享目录：`outputs/.video-runtime/<version>/node_modules`，各项目链接到它。不要硬编码某台 Mac 的 Chrome 或 compositor 路径；从环境发现或接受参数。浏览器路径传给 Remotion CLI。

```sh
npx --no-install remotion render src/index.jsx Intro output.mp4 --codec=h264 --browser-executable='/path/to/browser'
```

源文件生成出来不代表渲染成功。缺少依赖/浏览器时明确报告，不能把模板当成成片。可用系统 FFmpeg；使用 Remotion bundled FFmpeg 前验证支持的滤镜与动态库路径。某些 bundled 构建不支持常见滤镜。片段拼接前统一 fps、尺寸、编码和 track timebase，避免时长异常。

每次重渲染后从最终成片导出预览，防止预览仍是上一版。源码包包含时间轴、旁白、字幕、素材清单、生成提示词、构建说明，不含依赖缓存。
